# AI Usage Log – CodeSentinel

## Project
CodeSentinel – AI-Powered Code Security & Quality Auditor

## AI Tools Used
- ChatGPT – Development assistance, debugging, code reviews, architecture guidance, and documentation.
- Google Gemini – AI-powered analysis and validation of detected code issues.
- Ollama (Qwen2.5-Coder) – Local LLM inference and AI analysis fallback.

## Areas Where AI Was Used

### 1. Project Planning and Architecture
- Assistance in defining the project scope and analyzer architecture.
- Guidance on organizing the FastAPI backend and React frontend.
- Suggestions for integrating static analysis with LLM-based validation.

### 2. Backend Development
- Assistance with Python implementation and debugging.
- Guidance on repository scanning and language detection.
- Development support for security, code slop, coding gaps, and loose ends analyzers.
- Assistance with finding aggregation and deduplication.

### 3. AI Integration
- Integration guidance for Google Gemini and Ollama.
- Assistance with structured JSON responses.
- Guidance on batching findings and handling model failures.
- Design of AI-based finding validation and remediation recommendations.

### 4. Frontend Development
- Assistance with React component development.
- Debugging UI rendering issues and API integration.
- Implementation guidance for filtering, finding details, and JSON report downloads.

### 5. Testing and Debugging
- Assistance in identifying runtime errors.
- Guidance on testing analyzers using sample repositories.
- Debugging performance and improving error handling.

### 6. Documentation
- Assistance in preparing project documentation and setup instructions.
- README and repository documentation drafting.

## Human Contributions
- Defined the project objective and feature requirements.
- Designed and integrated the application components.
- Implemented and tested the backend analyzers and frontend.
- Configured AI providers and development environments.
- Reviewed AI-generated suggestions and adapted implementations.
- Tested the application using sample repositories.

## Responsible AI Usage
AI-generated suggestions were reviewed and tested during development. Static analysis findings are treated as potential issues, and AI validation is used as an additional assessment rather than a guarantee of correctness.

## Note
AI tools were used as development assistants. The final implementation, integration decisions, testing, and project submission were handled by the project developer.
